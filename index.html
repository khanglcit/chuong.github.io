Cần cấu hình Firebase

Chào mừng bạn! Để hệ thống chuông báo hoạt động realtime giữa các thiết bị, bạn cần liên kết với một project Firebase của riêng mình.

Các bước thực hiện cực kỳ đơn giản:

  1. Vào trang Firebase Console và tạo 1 Project.
  2. Tạo ứng dụng Web mới để lấy đoạn firebaseConfig.
  3. Bật tính năng Anonymous Sign-In trong mục Authentication.
  4. Tạo cơ sở dữ liệu Cloud Firestore (chọn Test Mode).
